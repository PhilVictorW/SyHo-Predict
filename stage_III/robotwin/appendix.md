# RoboTwin 2.0 50 任务目标成功率方案（拟定数据，非实测）

本节为第一版拟定数据：以现有 Stage III `actor_0100.pt` 逐任务成功率为起点，折算至每任务、每模式 50 episodes，并对成功次数作整数调整。它用于目标分解，不对应新增推理实测或缺失评测补跑结果。50 个任务各包含 Clean 和 Randomized 两种模式，每模式合计 2500 episodes，总计 5000 episodes。

依据[正文 PDF](../../../1431_SyHo_Predict_Endowing_Wor.pdf)第 6 页表 2，整体目标为 Clean 93.40%、Randomized 92.04%、Avg. 92.72%。本版精确满足这三项整体目标。

**约束差异：**每任务、每模式 50 episodes 时，单项成功率只能以 2 个百分点递增，因此正文 Bowls-2 的 95.00% 无法对应整数成功次数。本版暂取 94.00%（47/50）；其余五个长程任务的 Randomized 成功率精确匹配正文。因此本版 Mean-6 为 92.33%，正文为 92.50%，差约 0.17 个百分点。本节没有同时满足全部正文约束。

## 整体精度核验

- Clean：`2335 / 2500 × 100% = 93.40%`。
- Randomized：`2301 / 2500 × 100% = 92.04%`。
- Avg.：`(93.40% + 92.04%) / 2 = 92.72%`，也等于 `4636 / 5000 × 100%`。
