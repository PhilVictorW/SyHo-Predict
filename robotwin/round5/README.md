# 第五轮：固定分离门控，只比较未来辅助分项的权重

两组均继承round4/runs/future_aux/step_000200/adapter.pt（累计教师400步）。每组追加200步，batch4，lr1e-4，warmup10；每50步保存适配参数、FP32 master optimizer、RNG与辅助梯度上限。新增步数不与旧Stage II步数混淆。

固定此前独立轨迹复核的Plan0/Role3规则：v_base + 3*tanh(g)*(v_plan_role-v_plan_off)。代码保留审计的等价运算顺序。原始Qwen/DINO/LaWM/动作骨干、Plan token及门控参数均冻结，只训练future resampler、Goal/Local注入参数及辅助头。Plan内部计算仍保留，抵消的是其不依赖角色的增量。兼容候选包含原始LaWM和旧query，不是纯aba2消融。

- equal：位置、旋转、夹爪三个辅助loss等权。
- balanced：在32个有有效未来目标的训练集anchor上，使用初始化教师计算三项均值，取倒数并归一化至权重和3。固定权重后不再在线调节相对比例，不使用验证集标定。
- 两组同初始化、训练样本、采样种子、学习率和步数；辅助总系数仍按抽查query的动作/辅助梯度范数限制，上限1e-3、20步warmup。每50步记录三项梯度范数，该约束只覆盖抽查参数。
- 目标维度不变：6个未来偏移[8,24,40,56,72,88]，每个16维；Local预测1帧，Goal预测5帧。36步绝对动作窗口末值补齐；未来标签越界屏蔽。物理误差只统计真实动作帧。

训练过程记录action loss、三项原始辅助loss、加权辅助loss、辅助系数及梯度范数。16个固定样本每50步验证；每组结束后自动运行32条新的验证轨迹×2个噪声，排除之前80条调参/诊断/确认轨迹；两组共用这批样本。分别评估正确未来、错配未来、关闭角色和原始基线。辅助loss下降不能代替动作改善。

GPU0低CPU/IO优先级运行，25%进程显存预算；GPU2、5的旧Stage II和在线评测暂停状态不改变。启动前检查40GiB可用空间，每次保存保留32GiB；临时文件原子改名，保留所有完整检查点。有限梯度使用FP64累加后裁剪；非有限更新不写入优化器，累计3次终止并记录原因，不盲目重试。

启动：bash robotwin/round5/launch.sh
进度：tmux attach -t robotwin_round5_progress

不自动启动学生训练或在线评测。新检查点依赖原始冻结SFT和round4教师源检查点，不可直接交给旧推理服务。两个200步教师试验预计需要持续后台运行；恢复仅针对round5显式指定完整检查点，旧Stage II3000步不在此队列。

## 完成后的交叉诊断

两组200步及各自32轨迹×2噪声评估已完成。几何分项的正确未来收益已在辅助预测中出现，但动作端仍未通过未来收益筛查；平衡组动作指标略逊于等权组，不能仅凭加权辅助loss更小选它。

`audit_crossover.py` 固定等权组，交叉组合训练前后future resampler与Goal/Local动作注入参数。原始Qwen/DINO/LaWM/动作骨干、Plan和总门控固定；辅助头不参与动作输出。复用第五轮32条评估轨迹和一个噪声，逐样本核对最终组合重现既有指标。只在内存中替换适配参数，不写回模型，不更新优化器。

结果见 `crossover_audit/REPORT.md`，原始记录为同目录 `results.json`。`validation_before_after.json`记录固定调参集训练前后动作指标，`injection_scales.json`记录各保存步骤的逐层注入系数；Goal仅每四层有效，分析时应排除其余未使用槽位。
