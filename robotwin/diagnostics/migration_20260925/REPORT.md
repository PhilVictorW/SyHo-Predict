# RoboTwin 架构迁移与受控对照审计

完成时间：2026-09-25T21:38:45.549407+08:00。

## 结论

保留模块的参数迁移与核心计算基本一致。主要发现是 **原始 36 步预测契约被直接改成 8 步，造成严重的初始化行为变化**；新增 Plan tokens 即使关闭 Goal/Local 注入也不等价于旧动作头；目前教师/学生对新增 Goal/Local 条件的动作依赖很弱。证据支持优先检查这些设计选择，而不是归因于权重漏载或数据无法用于微调。以下全部是离线结果，不能替代闭环成功率。

## 已通过的迁移检查

- 原始检查点与新架构初始化逐张量比较：951 个保留张量，0 个不一致。允许新增/丢弃的模块仍按原设计处理。
- 完全旁路 Plan 与角色注入后，手写动作头与原 AlternateVLDiT 的 FP32 输出逐值一致。
- 当前特征不读取未来角色；Teacher Goal 与 Local 隔离；padding 不作为有效角色输入，全部通过。
- 归一化与原始 RobotwinEEFDataConfig 对应实现逐值一致；位置/夹爪 min/max、四元数直通、左右臂顺序正确，当前样本归一化往返误差为 0。
- Qwen 单样本 BF16 比较存在约 1.30% 特征相对差异；FP32 复核降为 1.7558228e-06，最大绝对误差 0.00011444092。双样本 BF16 检查逐值一致。没有发现显著的当前上下文位置编码/注意力逻辑偏差，BF16 并非逐位等价保证。
- 独立 Euler 对照与当前正式 sampler 在相同输入和噪声下逐值一致。

## 对照一：预测窗口、LaWM 与旧 query 输出

使用固定验证集前 8 个样本，固定噪声 seed=800+i。严格加载原始 VLM→LAM mapper 和 LaWM decoder，恢复原始未来视觉条件。比较所有方案输出的前 8 个动作与相同示范标签；每个样本为归一化 8×16 动作 MSE，再对样本取平均。36 步方案仍完整生成 36 步，仅指标截取前 8 步，不能与“只预测 8 步”混同。

| 原始权重的条件与预测长度 | 平均 MSE |
|---|---:|
| 完整原始条件，预测 36 步 | 0.00004667 |
| 完整原始条件，仅改为预测 8 步 | 0.71302444 |
| 36 步，仅去掉 LaWM | 0.01176843 |
| 36 步，仅去掉旧 query 输出 | 0.00789711 |
| 36 步，同时去掉两者（aba2 条件） | 0.01178673 |
| 8 步，同时去掉两者 | 0.71098468 |

36→8 的影响在 8 个样本中均明显，不只是重规划更频繁：时间有效动作 token 从 36 减至 8，改变了继承动作 Transformer 的自注意力输入。

去掉 LaWM/query 的误差均值主要由 episode 359、t=90 的瓶子样本拉高：完整条件误差约 0.000017，去 LaWM 后约 0.093803。不能据这一小样本均值声称所有任务等幅下降。

## 对照二：Plan tokens 的初始化并非恒等扩展

在 4 个样本、相同 aba2 条件下单独比较插入 Plan 与完全旁路新增模块：

- 固定 36 步，Plan 插入导致动作平均相对 L2 变化 **2.641%**。
- 固定 8 步，Plan 插入平均相对变化 **55.452%**。
- 关闭 Goal/Local 注入仅将注入残差置零，4 个 Plan tokens 仍参加 DiT 自注意力。初始化 residual scale=0.01 因而不保证旧行为保持。
- 变化不等于所有样本精度都变差：8 步设置下随机 Plan 在本次对照中反而降低了部分初始化误差。它是明显的迁移扰动，不能将其简单宣称为独立、必然的失败原因。

## 对照三：训练后的新增条件是否真正影响动作

使用相同 8 个验证样本与相同噪声，Stage I 教师取 1000 步，Stage II 学生取 2000 步。这里的教师 1000 步是离线模型审计，与已取消的 Stage II 1000 步在线评测不同。

| 模型 | 完整条件动作 MSE | 关闭 Goal/Local 注入 | 动作相对变化 |
|---|---:|---:|---:|
| Stage I 1000 | 0.01157911 | 0.01157586 | 0.456% |
| Stage II 2000 | 0.01180459 | 0.01179197 | 0.300% |

额外检查：教师未来 seed 置零后的动作平均相对变化约 0.366%；关闭学生 Goal→Local gate 后约 0.179%。Local 跨样本 cosine 约 0.96，是低区分度提示，不能单独证明表示完全塌缩。

训练后去掉 Plan 会显著增大离线误差，说明已训练模型已经适应并依赖包含 Plan 的动作结构。**不能把现有已训练检查点的 Plan 直接删掉当作修复。**同样，不应直接把现有 8 步学生的推理长度改成 36 步并宣称解决问题。

## 补充：短窗口的监督性质

同 8 个样本上，直接保持当前真实 EEF 状态的零阶保持基线，8 步平均归一化 MSE 为 0.01711619，36 步为 0.08485189。短窗口更接近当前姿态，但该对照没有证明模型实际采用这种捷径。

## 建议的修正与下一轮验收

1. 从原始 SFT 权重建立保留 36 步预测的兼容基线，先将“预测长度”与“执行后重新预测的间隔”拆开：预测 36/执行 36，与预测 36/执行 8 分别做固定任务和种子的闭环对照。不能将预测 8 与执行 8 当作同一改动。
2. 对新增分支实现可验证的恒等初始化/显式旁路：不仅限制 Goal/Local 注入，还要控制 Plan→Action 的自注意力影响。先要求在相同预测契约下关闭新路径能恢复基线，再逐步训练和打开新路径。
3. 在确认教师未来条件有动作价值之前，不以角色蒸馏 loss 的下降选择部署权重。扩大教师真实未来/错配未来/无未来消融，并在相同任务上比较 action-only 与加入蒸馏的训练。
4. 若更改训练预测长度，需要同步设计 action mask、训练标签长度、Local/Goal 时间偏移以及部署接口；不能只改一个 horizon 数字。本次未改动这些正在使用的设置。
