# 200 步 query-only 学生试验的独立离线复核

启动日期：2026-09-28。仅使用物理 GPU0，不启动优化器，不恢复旧 Stage II3000，不启动在线 rollout。

训练已正常完成 200/200 步。`query_pilot/query_update_audit.json` 记录了实际参数更新；step200 的 Goal/Local 查询分别有约 13.30% / 31.45% 的元素在转换到 BF16 后发生变化，排除了“参数实际上没有改变”的情况。

本次预先指定 step200 为主要评估对象，同时展示初始化、step50/100/150 的探索性对照，不能看完结果后挑出最好的一步再宣称独立验证成功。

- 常规样本：排除此前使用过的 176 条验证轨迹，再固定抽取 32 条，每条 2 个噪声种子。
- 末尾压力样本：另外 8 条不重叠轨迹，分别取剩余 1、8、24、36 帧的锚点，各 2 个噪声种子。
- 合计 128 组配对，每组同时比较 5 个学生 checkpoint 和原始 actor 基线。
- 只解码当前三路相机图像。当前图像和指令是模型唯一输入；剩余长度仅用于样本选择和统计，角色有效性恒为真。
- 先复现旧固定验证集上的 step0/200、sample0/15 结果，误差必须小于 1e-6；实际预检差值为 0。
- 误差指标保持原有口径：真实存在的动作帧上统计位置 cm、姿态角度、夹爪 MAE。末尾重复补齐动作只用于保持模型的 36 token 接口，不把补齐帧计入指标。
- Bootstrap 按独立 episode 重采样，不能把同一条轨迹的不同末尾锚点或噪声当成独立轨迹。

预设筛查要求：主要候选各项均值不超过初始化及原始基线的 1.05 倍，且相对初始化的标准化误差增量 95% 区间上界不超过 0.05。末尾各剩余长度分别检查。通过仅表示此样本上的非退化筛查通过，不等于训练有收益，更不等于闭环成功率已恢复。

运行：`bash robotwin/round7/launch_postpilot.sh`（已有运行/manifest 时拒绝覆盖）。

查看：`tmux attach -t robotwin_round7_progress`，切到 `postpilot` 窗口；工作进程另在 `robotwin_round7_postpilot` 会话，正常结束后该工作会话自动退出，进度窗口保留。

结果目录：`postpilot_eval/`，包括预先固定的 `manifest.json`、`preflight.json`、持续更新的 `partial.json` 和 `status.json`，结束后生成 `results.json` 与 `REPORT.md`。

后续决策必须同时看常规和末尾结果。目前兼容候选保留了原始 LaWM 条件及旧 query；它仍不是纯 aba2 消融架构。后验未来信息和 KD 的增益尚未得到证明。
